# Badge_AutoMake
A Python program to automake badge from a name list and a pdf template

## 一个很 trivial 的胸牌制作脚本

**原本用作复旦大学化学系100周年系庆会场专家胸牌的一键生成**

### 使用方法：

**同一目录下**

- 需要生成胸牌的专家编号、姓名、单位分为三列保存为 `Guest_List.csv` 文件；
- 胸牌PDF模板保存为 `Template.pdf` 预留出加入姓名和单位的位置；
- 默认使用字体为 `Microsoft Yahei SemiBold` 。

**然后就行了**
